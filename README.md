## 买 VPS 前先定三件事：内存、机房、虚拟化

### 内存买多大：按用途查表

内存是大多数应用最先撞上的瓶颈，配置表的其余参数都可以妥协，这个尽量别省。对照下面的表找自己的场景：

| 用途 | 内存建议 |
| --- | --- |
| 学习 Linux、跑一两个脚本 | 512MB–1GB |
| 个人博客 / 静态网站 | 512MB–1GB |
| WordPress 单站 | 1–2GB |
| 跑 Docker、两三个小服务 | 2–4GB |
| 小型数据库、游戏服务器 | 4GB+ |
| 本地跑大模型推理 | 8GB 起步，且需确认机型支持 |

两个提醒：一是别“以防万一”买大，多数 VPS 后续升配不难，起步买小、不够再加，钱花在刀刃上；二是存储优先选 NVMe，商家只写"SSD"不注明类型的，多半是 SATA SSD，跑数据库时差距会被放大。RackNerd 促销档标注的是 SSD，对上面这些轻量场景够用。

### 机房怎么选：离用户近，不等于离你近

原则一句话：机房选在离你的用户最近的地方。选错区域，多出来的延迟从 50ms 到 200ms 不等，再贵的机器用起来也发闷。

这里要对中国用户多说一句。美西机房到中国大陆的物理延迟就在 150ms 上下，这是光速决定的，谁都绕不过去；线路质量决定的是这个数字的稳定程度。圈内常见的排序是 CN2 GIA 优于 AS9929、再优于 AS4837 和 CN2 GT，商家页面出现这类字样通常意味着对国内更友好，价格也贵一截。RackNerd 走的是普通国际线路，白天访问没问题，晚高峰可能有波动——它适合挂服务、学习、跑自动化，不适合直接给国内用户当生产站的前端。

所以决策很清楚：服务不面向国内访问，或者可以套一层 CDN，RackNerd 这类普通线路完全够；对国内延迟敏感、预算也充足，该去看 CN2 GIA 类商家（搬瓦工、DMIT 是这个路线的代表），年费按 RackNerd 的三到五倍准备。

### 虚拟化只认 KVM，OpenVZ 别碰

这是买 VPS 唯一一条建议当成硬规矩的：**只买 KVM 虚拟化的套餐**。KVM 是完整的硬件虚拟化，你拿到独立内核，Docker、WireGuard 原生可用，内存是实打实分配给你的。OpenVZ 容器方案共享宿主内核，Docker 装不上、内存经常是“可突发”的虚数，商家超售起来性能完全看运气。

判断方法：商品页没写虚拟化类型，下单前直接问客服一句，或者去主机论坛搜这家商家的讨论。RackNerd 全线 KVM，所有套餐都给完整 root 权限，这条可以放心。

## 开通后第一小时做什么

邮件到手别急着装应用，先花半小时把底子打好：

- SSH 登录，立刻改掉初始 root 密码，或者直接换成密钥登录。
- 更新系统：Debian/Ubuntu 执行 `apt update && apt upgrade -y`。
- 开 BBR：Linux 内核自带，往 `/etc/sysctl.conf` 加两行参数再 `sysctl -p` 生效，有丢包时提升明显。
- 装个防火墙只放行需要的端口，ufw 一条命令的事。
- 设置备份：面板里先开快照，重要数据再同步一份到对象存储。

最后一条多说一句：任何 VPS 都有挂的可能性，单机可靠性再高的商家也不例外，定时备份是唯一靠谱的保险。

## 新手最常见的五个坑

1. **上来就买大配置**。内存翻倍价格翻倍，多数用途 1–2GB 就够，不够再加。
2. **机房跟着自己走**。你在北京、用户在欧洲，机房就该放欧洲。别按“我在哪”选。
3. **只比价格不看条款**。流量超了是限速还是停机？快照收不收费？退款窗口几天？这些都在条款里，下单前花两分钟翻一遍。
4. **不做备份**。便宜的 VPS 也要做备份，省下的那点钱不够一次数据丢失的折腾。
5. **新商家一次锁三年**。大额多年折扣要有前提：你验证过这家商家的网络和客服。RackNerd 这类年付金额小、续费同价的还好；没验证过的商家，先年付试一年。
